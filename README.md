# FPV КАДЕТ (FPV Online) 🚁

**FPV КАДЕТ** — это веб-симулятор полетов на FPV-дроне (квадрокоптере), разработанный с использованием React, Vite и Three.js. Проект создан в образовательных и тренировочных целях (для ГБОУ ГККШИ ИМ. В. В. УСМАНОВА). Работает прямо в браузере и поддерживает управление как с клавиатуры, так и с помощью настоящих FPV-пультов (RadioMaster, пульты на базе Betaflight) или обычных геймпадов (Xbox, DualShock).

## 🚀 Особенности симулятора

- **3D-графика в браузере**: Реализована на базе Three.js с поддержкой PBR-материалов, освещения и теней.
- **Два режима полёта**:
  - **Angle (Стабилизация)** — отлично подходит для новичков. Дрон выравнивается при отпускании стиков.
  - **Acro (Акробатический)** — полный ручной контроль для выполнения фристайл-трюков, как на реальном гоночном FPV-дроне.
- **Поддержка контроллеров**:
  - Клавиатура
  - Стандартные геймпады (Xbox / PlayStation)
  - FPV Аппаратуры управления (режим джойстика)
- **Кастомизация физики и графики**: Настройка чувствительности стиков, гравитации, трения, FOV (поля зрения) камеры и визуальных FPV-эффектов (помехи, глитчи, хроматическая аберрация).
- **Редактор карт**: Встроенный редактор для создания собственных тренировочных локаций.
- **Вид от 1-го и 3-го лица**: Мгновенное переключение (клавиша `Tab`).

## 🛠 Установка и запуск (для разработчиков)

1. Убедитесь, что у вас установлен Node.js.
2. Склонируйте репозиторий или перейдите в папку проекта.
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Запустите локальный сервер для разработки:
   ```bash
   npm run dev
   ```
5. Откройте проект в браузере по указанному локальному адресу (обычно `http://localhost:5173/`).

## 🎮 Управление (Клавиатура)

- `W` / `S` — Газ (Тяга / Throttle) вверх / вниз
- `A` / `D` — Рысканье (Поворот / Yaw) влево / вправо
- `Стрелки Вверх/Вниз` — Наклон (Pitch) вперед / назад
- `Стрелки Влево/Вправо` — Крен (Roll) влево / вправо
- `Tab` — Смена вида (FPV / от 3-го лица)
- `Esc` — Открыть/Закрыть меню паузы и настроек

*Для тренировок настоятельно рекомендуется использовать геймпад или FPV-пульт.*

## 💡 Что можно улучшить и добавить в будущем

Проект имеет отличную базу, но есть множество путей для его дальнейшего развития:

### Механика и Физика:
1. **Продвинутая аэродинамика**: Добавить симуляцию ветра, турбулентности и эффекта земли (ground effect) для максимального реализма.
2. **Система повреждений (Damage System)**: Ломка пропеллеров, ухудшение управления при столкновениях, "черепаший режим" (Turtle Mode) для переворота дрона после падения.
3. **Настройка PID-регуляторов**: Добавить интерфейс для тонкой настройки PID-ов, как в Betaflight, чтобы пилоты могли настраивать отклик под себя.
4. **Разные классы дронов**: Добавить выбор между Tiny Whoop, 5-дюймовыми фристайл-сборками и тяжелыми синевупами с разной физикой массы и инерции.

### Игровой процесс:
1. **Мультиплеер (FPV Online)**: Реализовать сетевую игру через WebRTC или Socket.io для совместных полетов и гонок с друзьями.
2. **Гоночные трассы и Checkpoints**: Добавить систему колец (ворот) с таймером круга, таблицей рекордов (Leaderboard) и режимом гонки на время.
3. **Звуковое сопровождение**: Динамический звук моторов, зависящий от оборотов (RPM), свист ветра в камере, звуки ударов.
4. **Запись полетов (DVR/Blackbox)**: Возможность записывать свой полет и пересматривать его от третьего лица (Replay system) с отображением стиков на экране.

### Интерфейс и Графика:
1. **Погодные условия**: Добавить дождь, туман, разное время суток (закат, ночь с неонами).
2. **OSD (On-Screen Display) как в реальном FPV**: Вывод заряда виртуальной батареи, угла наклона горизонта, тока и напряжения на экран.
3. **Улучшение редактора карт**: Сохранение созданных карт в LocalStorage или JSON, удобный экспорт/импорт трасс, добавление новых видов препятствий (деревья, здания, движущиеся объекты).
